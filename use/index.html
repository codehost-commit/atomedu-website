How it works

From class goal to printable worksheet.

Teachers describe the assignment they want, review the generated draft, then save or print the final version. The live app supports structured prompts, formatted STEM notation, and stored assignments.

Step 1

Describe the assignment

Set the class, topic, question mix, number of items, difficulty, directions, and diagram needs.

Step 2

Review the result

Check the worksheet before use. Edit the prompt and regenerate if you want a different tone or question balance.

Step 3

Save and print

Signed-in teachers can save assignments and download a printable PDF from the live app deployment.

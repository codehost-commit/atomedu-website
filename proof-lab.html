Notation & engine coverage

Use the keyboard below to insert templates, then fill each gray box. Select part of an expression before inserting a fraction or power to wrap your selection.

Each field has an optional synchronized LaTeX source editor. Systems, geometry proofs, and matrix operations can also use Advanced structured mode.

Notation validation checks the LaTeX. Proof verification separately checks the mathematics using the engine’s supported rules. Neither a well-formed expression nor a graph establishes a proof.
